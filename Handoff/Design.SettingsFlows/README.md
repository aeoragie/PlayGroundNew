# Handoff: 계정 설정 플로우 3종 (Settings Flows)

> 대상 저장소: `C:\Workspace\PlayGroundNew` · 압축 해제 위치: `Handoff\Design.SettingsFlows` (신규)
> DesignWorkOrders ⑥ — `Design.Settings` 계정 탭의 **무동작 버튼 3개**에 실제 플로우를 붙인다. 버튼 위치·행 구조는 기존 Settings SPEC 그대로, 이 패키지는 **그 뒤에 열리는 모달·상태**만 정의.
> 브랜드 마크(Google 4색 / Kakao `#191919` 말풍선 / LINE 공식)는 `Design.Auth.Onboarding` 승인본 SVG를 그대로 사용 — 재작도 금지.

## ① 이름 변경 (일반 확인 모달 / 모바일 바텀시트)
- 입력: 한글 2~10자 또는 영문 2~20자 · 특수문자·숫자 불가 · blur 후 인라인 검증
- **동명이인 허용**(중복 검사 없음 — 실명 서비스)
- 모달 안에 반영 범위를 명시:
  - **바뀌는 곳**: 계정 이름 · 팀에 보이는 보호자 이름 · 알림 발신 이름
  - **바뀌지 않는 곳**: 자녀(선수) 이름 · 이미 남긴 리뷰의 마스킹 표기(김**) · 지난 지원서에 기록된 이름
- **30일 내 2회 제한** — 초과 시 버튼 비활성 + 캡션 "이름은 30일에 두 번까지 바꿀 수 있어요 · 다음 변경 가능 8/12"
- 성공 = 토스트 "이름이 변경됐어요" + GNB·프로필 즉시 반영 · 변경 로그 보관(운영 추적)

## ② 로그인 수단 연결 / 해제
- 행 구조: 브랜드 아이콘 타일 + 이름 + 마스킹 이메일·연결일 + "연결됨" teal 뱃지 + 해제(PC 텍스트 / 모바일 ⋯ 바텀시트)
- 미연결 = 점선 행 + "연결하기" 버튼 → OAuth 팝업 → 성공 토스트 "Kakao가 연결됐어요"
- **마지막 1개는 해제 불가** — 비활성 버튼이 아니라 자리에 "유일한 로그인 수단" 회색 캡션(왜 못 하는지 보여준다)
- 다른 계정에 이미 쓰인 소셜 = 인라인 오류 "이미 다른 계정에 연결된 카카오예요"
- 해제 = **파괴 모달**(레드, 기본 포커스=취소) + 본문에 남은 수단 수 명시
- 이메일은 항상 마스킹 표기(kim***@gmail.com)
- **LINE**은 채널 미발급이라 "준비 중" 회색 행(현행 보류 결정 유지 — 연결 버튼 없음)

## ③ 데이터 내려받기 (요청 → 생성 → 다운로드)
- 요청 모달: 포함 항목 체크 3종
  1. 계정·프로필(이름·연락처·역할·자녀 연결)
  2. 경기 기록·커리어(자녀별 출전·기록·수상)
  3. 요청·신청 내역(연결·열람 승인·지원·수정 신청)
- 형식: **JSON + 사람이 읽는 CSV 요약** · 사진·영상 원본 제외(URL 목록만)
- 안내: 준비 최대 **24시간**, 완료 시 알림, 링크는 **7일** 뒤 만료
- 요청 후 계정 관리 절의 행이 상태로 바뀜(버튼 대신):
  - **준비 중**: 스피너 + 요청 시각 + "요청 취소"
  - **준비 완료**: teal 테두리 + 크기·만료일 + "내려받기"(네이비)
  - **실패**: 레드 카드 + "다시 요청"
- 동시 진행 1건 · 재요청 쿨다운 24시간 · 다운로드는 서명 URL(7일·3회 상한) · 완료 알림 = **알림 센터 + 이메일** · 자녀 데이터는 연결된 자녀분만

## 스키마
- `Users.DisplayName` + `SoccerNameChangeLogs`(UserId · 이전 · 이후 · ChangedAt)
- `UserSocialLinks`(UserId · Provider · ProviderUserId · MaskedEmail · LinkedAt)
- `SoccerDataExportRequests`(UserId · 상태 Pending/Ready/Failed · FileUrl · SizeBytes · ExpiresAt · DownloadCount)

## API 경계
- 내려받기 생성은 **백그라운드 잡** — 요청 API는 접수만 반환(동기 생성 금지)
- OAuth 연결/해제는 기존 인증 파이프라인 재사용(신규 흐름 만들지 말 것)

## Files
- `Settings Flows.dc.html` — PC(3종 모달·상태) / `Settings Flows Mobile.dc.html` — 모바일(390px, 바텀시트)
- `support.js` — 레퍼런스 실행용 (구현 대상 아님)
