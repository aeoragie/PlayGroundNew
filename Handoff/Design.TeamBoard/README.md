## ⚠ TeamPublicHome에 대한 변경 사항 (구현 시 함께 반영)
- **6탭 구성은 그대로 유지**(소개/선수단/시즌성적/모집/진학·진로/리뷰) — **"소식" 탭을 신설하지 않는다**(모바일 탭 개수 상한 유지)
- 공개 글의 목적지 = **① 소개 탭의 마지막 섹션 "팀 소식"** — 코칭스태프 절 아래, 카드형 **최대 3건**, 3건 초과 시 "지난 소식 보기"로 같은 탭 내 확장(`/team/{slug}/about#news`)
- 이 섹션은 `SPEC.TEAMPUBLICHOME.md` ① 소개 절에 추가되어야 한다(README 탭 목록은 변경 없음)
- 공개 글 0건이면 **섹션 자체 숨김**(방문자에게 빈 상태 노출 안 함)

## 목록 (팀 대시보드 · 게시판)
- 세그먼트: 전체 N / 공지 N / 자료 N — 유형은 **공지·자료 2종만**
- 행: 유형 뱃지(공지=네이비 채움 / 자료=회색) + 제목 + 메타(작성자·날짜·첨부·조회) + **눈 아이콘 = 공개홈 노출 중** + ⋯
- **고정 글 최대 2개** — 네이비 테두리+틴트, 목록 최상단
- 조회수는 관리자·코치에게만 표시 · 더 보기 20개(TableList)
- ⋯ = 수정 / 고정 전환 / 공개 전환 / 삭제(레드, 맨 아래) · 모바일 = 바텀시트
- 주 버튼 "＋ 글 작성" 오렌지 42px(대시보드 화면당 1개 규칙 내), 모바일은 목록 하단 풀폭

## 작성 (PC 모달 / 모바일 바텀시트)
- 유형 라디오 카드 2개 · 제목 2~60자 · 내용 2000자 카운터
- 첨부: pdf·이미지·hwp, 10MB, **최대 3개**(ImageUploader 다중 규칙 준용, 모바일은 OS 시트 위임)
- **공개 스위치 기본 끔** — 팀 내부가 기본값(실수 공개 방지). 헬퍼 "켜면 소개 탭 '팀 소식'에 보여요 · 끄면 소속 보호자만"
- 공개 켜도 **첨부 다운로드는 로그인 필요**(공개홈에서는 파일명만 표시)
- **공지 발행 시 로스터 보호자 전원 알림 / 자료는 알림 없음**(알림 피로 방지)

## 열람
- **보호자 뷰**(허브 자녀 카드 → 팀 소식): 읽기 전용 내비게이션형 행 + **안읽음 오렌지 점** · 여러 자녀가 다른 팀이면 팀명 접두 · 작성 버튼 미노출
- 빈 상태: 관리자 = Tier A + 네이비 CTA / 보호자 = "팀이 글을 올리면 여기에 보여요"(CTA 없음)

## 권한
| 동작 | 주체 |
|---|---|
| 작성 | 팀 관리자 · 코치 — 그 외에는 버튼 **미노출**(비활성 아님) |
| 수정 | 작성자 본인 + 팀 관리자(코치 글 포함) · "수정됨" 표기, 재알림 없음 |
| 열람 | 로스터 소속 선수의 보호자 + 팀 스태프 · **편입 이전 글도 열람 가능**(팀 히스토리) · 로스터 이탈 시 즉시 차단 |
| 삭제 | 파괴 모달(첨부 함께 삭제 명시) · **소프트 삭제 30일 보관** · 공개 글은 공개홈에서도 즉시 사라짐 |
