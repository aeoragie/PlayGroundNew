# Handoff: 에이전트 축 (Agent Dashboard & Profile)

> 대상 저장소: `C:\Workspace\PlayGroundNew` · 압축 해제 위치: `Handoff\Design.AgentDashboard` (신규)
> DesignWorkOrders ⑤ · 설계 결정 4(에이전트 축은 **별도 서비스**로 분리 — DB 공유·SSO) 전제.
> **구현 우선순위 = 최후순위.** 기본은 feature flag OFF, 기존 Phase C6 구현분(보호자 심사 화면) 유지.
> violet `#6d4bd8`은 에이전트 요소 전용 토큰(다른 곳에 쓰지 말 것).

## ⚠ 이 패키지의 핵심 — 책임 분리

| PlayGround (본 서비스) | 에이전트 서비스 (별도) |
|---|---|
| 요청 **조회·심사**(승인/거절/차단) — Design.AgentViewApproval | 요청 **생성**(어느 선수에게·왜) + 쿨다운 강제 |
| 승인 상태·남은 일수 표시, **만료 자동 처리** | 열람 로그 **적재** |
| 승인 범위 내 선수 정보 노출 판단(공개 범위 스위치 존중) | 에이전트 **신원 인증·심사**(자격·소속 서류) |
| 열람 기록을 보호자에게 **표시** | 에이전트 자기 프로필·중개 이력 관리 |
| 에이전트 신원 카드 **렌더** | 조건 검색(성적·연령) — DECISION.TEAMEXPLORE C2 |

**쓰기 경계**: 에이전트 서비스는 `Agents`·`AgentViewRequests`(생성만)·`AgentViewLogs`만 쓰기, 선수·팀·기록 테이블은 **읽기 전용**. 심사 결과(승인/거절/차단·만료)는 **PlayGround만 쓰기** — 같은 행을 양쪽이 쓰지 않는다.

## 에이전트 대시보드 — 요청 현황 (에이전트 서비스 화면)
- 요약 3칸: 열람 중(violet) / 대기 / 이번 달 만료
- 행 상태 4종: **대기**(오렌지톤) / **열람 중**(teal + "남은 N일") / **만료**(회색) / **거절**(회색 + "N/N부터 재요청 가능")
- **거절 사유는 에이전트에게 전달하지 않음**(보호자 보호 — 기존 denied 규칙 계승)
- 만료 3일 전 알림 · 요청 생성 진입은 **선수 프로필의 "상세 정보 열람 요청" 버튼이 유일**(목록에서 대량 요청 불가)

## 열람 로그 (같은 테이블, 방향만 다름)
- 에이전트 서비스가 **적재**, PlayGround(보호자 화면)가 **표시** — `AgentViewLogs` 단방향
- 기록 항목 = 열람 대상 · 행위 · 시각만(스크린샷·다운로드 개념 없음)
- 보호자는 로그를 보고 언제든 철회(철회는 PlayGround 쓰기)

## 에이전트 공개 프로필 (PlayGround 렌더, 읽기 전용)
- **Design.AgentViewApproval의 에이전트 신원 카드와 동일 컴포넌트**: violet 보더 `rgba(109,75,216,.3)` + 헤더 배경 `.06` + 아바타 + "인증 에이전트" 뱃지 + 소속·등록연도 + 3스탯(중개 이력 / 평가 / 활동 지역)
- **인증 에이전트만 요청 가능** — 비인증은 요청 버튼 자체가 없음(인증 심사는 에이전트 서비스 몫)
- **연락처·이메일 미표시** — 접촉은 플랫폼 내 메시지로만

## feature flag
- **OFF(기본)**: 선수 프로필 "상세 정보 열람 요청" 버튼 · 에이전트 관련 알림 · 역할 선택의 에이전트 항목 **전부 미노출**(비활성 아님). 이미 승인된 건은 데이터 보존
- **ON**: 보호자 심사 화면·알림·열람 로그 표시 활성. 에이전트 로그인은 **SSO로 에이전트 서비스 리다이렉트** — 본 서비스에 에이전트 전용 대시보드를 만들지 않는다

## 만료 · 차단 (PlayGround 단독 판정)
- 승인 **30일 자동 만료**(연장 없음 — 재요청) · 거절 시 동일 에이전트 **30일 쿨다운**(서버 강제)
- "이 에이전트의 요청 다시 받지 않기" = 영구 차단(설정에서 해제 가능)

## 불변 규칙
- 승인 범위에도 **연락처는 절대 포함되지 않음**
- 공개 범위 스위치가 끈 항목은 **승인과 무관하게 계속 숨김**
- 조건 검색(성적·연령 필터)은 본 서비스에 만들지 않음(DECISION.TEAMEXPLORE)

## 스키마 (공유 DB)
- `Agents`(인증 상태 · 소속 · 등록연도 · 활동지역) — 에이전트 서비스 쓰기
- `AgentViewRequests`(AgentId · PlayerId · 상태 Pending/Approved/Denied/Expired/Blocked · RequestedAt · DecidedAt · ExpiresAt) — 생성=에이전트 서비스, 심사=PlayGround
- `AgentViewLogs`(RequestId · Action · TargetRef · ViewedAt) — 적재=에이전트 서비스, 표시=PlayGround

## Claude Code 첫 프롬프트 예시
```
Handoff/Design.AgentDashboard/README.md와 두 dc.html을 읽고
Handoff/Design.AgentViewApproval도 확인해(신원 카드는 그 컴포넌트를 재사용).
이번 단계는 본 서비스 몫만 구현한다:
1) feature flag(기본 OFF) 게이팅 — 요청 버튼·알림·역할 항목 미노출, 기존 승인 데이터 보존.
2) 만료(30일)·거절 쿨다운(30일)·차단 판정을 PlayGround에서 단독 수행 + 만료 3일 전 알림.
3) 보호자 화면에 열람 로그 표시(AgentViewLogs 읽기) + 철회.
4) 에이전트 신원 카드 컴포넌트 공유(심사 화면·프로필 동일), 연락처 미표시.
에이전트 대시보드·요청 생성·열람 로그 적재·인증 심사는 만들지 마(별도 서비스 몫).
완료 후 flag OFF/ON 두 상태 + 승인→만료→재요청 시나리오로 검수 요청해.
```
