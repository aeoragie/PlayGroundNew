Design.AgentViewApproval의 에이전트 신원 카드와 동일 컴포넌트(violet 보더 + 헤더 `.06` + 3스탯) — 요청 심사 화면·프로필 화면이 같은 카드를 공유. 인증 에이전트만 요청 가능(비인증은 요청 버튼 자체 없음 — 인증 심사는 에이전트 서비스 몫). 연락처·이메일은 표시하지 않음(플랫폼 내 메시지로만 접촉).
feature flag · 규칙
flag OFF 기본값. 선수 프로필의 "상세 정보 열람 요청" 버튼·에이전트 관련 알림·역할 선택의 에이전트 항목 전부 미노출(비활성 아님). 이미 승인된 건은 그대로 유지(데이터 보존)
flag ON 보호자 심사 화면(AgentViewApproval)·알림·열람 로그 표시 활성. 에이전트 로그인은 SSO로 에이전트 서비스로 리다이렉트 — 본 서비스에 에이전트 전용 대시보드를 만들지 않는다
만료·차단 승인 30일 자동 만료(연장 없음 — 재요청) · 거절 시 동일 에이전트 30일 쿨다운(서버 강제) · "요청 다시 받지 않기" = 영구 차단(설정에서 해제 가능) · 차단·만료 판정은 PlayGround가 단독 수행
불변 승인 범위에도 연락처는 절대 포함되지 않음 · 공개 범위 스위치가 끈 항목은 승인과 무관하게 계속 숨김 · 조건 검색(성적·연령 필터)은 본 서비스에 만들지 않음(DECISION.TEAMEXPLORE)
스키마(공유 DB): Agents(인증 상태·소속·등록연도·활동지역 — 에이전트 서비스 쓰기) / AgentViewRequests(AgentId·PlayerId·상태 Pending/Approved/Denied/Expired/Blocked·RequestedAt·DecidedAt·ExpiresAt — 생성=에이전트 서비스, 심사=PlayGround) / AgentViewLogs(RequestId·Action·TargetRef·ViewedAt — 적재=에이전트 서비스, 표시=PlayGround). 사용 패턴: AvatarBadge(violet)·TableList·FeedbackPatterns·EmptyStates — 신규 패턴 없음. 이 패키지의 구현 우선순위는 최후순위(Phase C6 완료분 유지 + flag OFF 기본).
