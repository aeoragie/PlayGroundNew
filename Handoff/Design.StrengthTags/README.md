# Handoff: 선수 강점 태그 (Strength Tags)

> 대상 저장소: `C:\Workspace\PlayGroundNew` · 압축 해제 위치: `Handoff\Design.StrengthTags` (신규)
> DesignWorkOrders ③ — 공개 프로필 히어로에 이미 존재하는 `#왼발 마무리 · #침투 · #스피드` 칩의 **입력·저장·공개 범위**를 확정한다(칩 스타일은 SPEC.PLAYERPUBLICPROFILE 히어로 규칙 그대로 계승).

## 원칙
- **최대 5개 · 1~12자 · 프리셋 우선 + 자유 입력 허용**
- 강점은 자기 서술 — 검증·승인 없음(기록이 옆에 함께 보이는 구조로 과장 억제)
- 검색 인덱스에 **포함하지 않음** (`DECISION.TEAMEXPLORE` 조건 검색 금지 원칙)

## 편집 (선수 대시보드 · 프로필)
- 칩 입력 박스: 추가된 태그(네이비 텍스트 + `#f1f3f8` + X) + 인라인 텍스트 입력 · Enter·쉼표로 추가 · 카운터 "3 / 5"
- **프리셋**: 포지션별 8개(GK/DF/MF/FW) — 서버 상수. 이미 추가한 태그는 회색 비활성. 모바일은 가로 스크롤
- 순서: PC 드래그, 모바일 ⋯ "맨 앞으로" — **앞 3개가 카드 뷰에 노출**
- 저장은 프로필 폼의 기존 저장 버튼(즉시 저장 아님)

## 검증
| 항목 | 규칙 |
|---|---|
| 개수 | 5개 상한 — 도달 시 입력 비활성 + "태그는 5개까지 넣을 수 있어요" |
| 길이 | 1~12자(공백 포함) · `#`는 **표시용**(저장값 미포함) · trim · 중복은 조용히 무시 |
| 금지 | 연락처·SNS·링크·타 선수 실명 — 패턴 검사(숫자 8자 이상 연속 · `@` · `http`) → 인라인 "연락처나 링크는 넣을 수 없어요" |
| 권한 | 보호자·선수 본인(중등 이상)만 · **팀 관리자 편집 불가** · 신고는 공개 프로필 기존 경로 |

## 공개 범위
- `SoccerPlayerFieldVisibilities`에 **"강점 태그" 항목 추가(기본 켬)** — 키·몸무게·주발과 같은 항목별 스위치 체계에 편입
- 스위치는 프로필 폼이 아니라 **공개 범위 설정 절**에 배치(폼 안 스위치 금지 규칙 준수)
- 끄면 공개 프로필·카드 뷰·선수단 카드에서 모두 숨김

## 노출 3곳
1. **공개 프로필 히어로**(기존 위치 — 공개 항목 칩 아래): 11.5px 700 네이비 + `#f1f3f8`, radius 99, padding 3×11 — **5개 전부 표시**(줄바꿈 허용, 모바일 동일)
2. **선수 카드 뷰(다크)**: teal `#2EC4B6` 텍스트 + 흰 8% 배경(카드 스탯 칩 톤 계승) — **앞 3개**, 4개 이상은 "+N"
3. **선수단 카드 뷰**(팀 공개홈·대시보드): **첫 태그 1개 + "+N"**만(정보 밀도 유지) · **리스트 뷰는 미노출**
- 태그가 없으면 영역 자체 생략(빈 상태 없음)
