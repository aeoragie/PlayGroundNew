# SPEC.APPLICATION — 지원 (PC + 모바일)

토큰·카드·행 규칙은 SPEC.TEAMPUBLICHOME ④ / SPEC.TEAMDASHBOARD §6 계승. 카피는 아래 확정 텍스트 그대로.

## 카피 고정
- 공고 카드 버튼: "지원하기"(네이비) / 마감 시 "모집 마감"(비활성) / 기지원 "지원 완료 · 상태 보기"
- 폼 제목: "{팀명}에 지원하기" + 부제 = 공고 제목
- 필드 레이블: 지원 선수 / 희망 포지션 / 자기소개 / 연락처
- 헬퍼: "연결된 자녀 중 선택 — 프로필 정보(생년·포지션·기록)가 함께 전달돼요" / "공고에 명시된 포지션만 표시" / "계정에 등록된 번호 · 팀에는 수락 후에만 전달돼요"
- 자녀 미연결: "먼저 자녀를 연결해 주세요" + [자녀 연결하기]
- 중복 시 인라인: "이미 지원한 공고예요 · 상태를 확인해 보세요"
- 성공 토스트: "지원이 전달됐어요"
- 팀 측 ⋯: 프로필 보기 / 테스트 요청 (검토중으로) / 수락 — 선수단 초대 / 보류(레드)
- 보류 모달: "지원을 보류할까요?" / "{선수명} · 보류하면 지원자에게 알림이 가요. 30일 후 다시 지원할 수 있어요." / [취소/보류]
- 지원자 측 상태 문구: 대기="팀에 전달됐어요" / 검토중="팀이 확인했어요" / 수락="함께하게 됐어요 — 초대를 확인해 주세요" / 보류="이번에는 함께하지 못했어요"
- 선수단 초대 알림: "{팀명}이 {선수명}을 선수단에 초대했어요" + [초대 확인]

## 검증
- 필수: 지원 선수·희망 포지션 (자기소개는 "(선택)" — 없어도 제출 가능)
- 자기소개 500자 초과 = 카운터만 레드(입력 차단 안 함)
- 마감·정원 충족 공고는 폼 진입 차단(카드에서 비활성)
- 미성년 지원은 보호자 계정만 — 선수 본인 계정으로는 제출 불가(안내 문구로 종료)

## 상태 머신
`Pending(대기) → Reviewing(검토중) → Accepted(수락) | Rejected(종료)`
- 수락 이후 편입은 별도 트랜잭션(보호자 동의) — 지원 상태는 Accepted에서 고정
- 대기 상태에서만 지원자 취소 가능 · 검토중부터는 팀 응답 대기
