# SPEC.SCHEDULE — 팀 일정 (PC + 모바일)

토큰·행 레이아웃은 SPEC.TEAMDASHBOARD.md §3 계승. 카피는 아래 확정 텍스트 그대로.

## 카피 고정
- 섹션 헤더: "일정" + "{YYYY}년 {M}월" · 버튼 "＋ 일정 추가"(오렌지 — 화면당 1개 규칙 내 기존 위치 유지)
- 캡션: "경기 일정은 공개 홈페이지 Schedule 탭에 자동 노출 · 학부모는 구독 캘린더(Google/Apple)로 받아볼 수 있어요"
- 모달 제목 "일정 추가" · 필드 레이블: 유형/날짜/시간/상대 팀/장소/제목 · 스위치 "공개 홈페이지에 노출" + 헬퍼 "끄면 팀 내부(대시보드)에서만 보여요" · 버튼 [취소/추가하기]
- 종료 메타: "종료" / "종료 — 결과 입력됨" · 비공개 메타: "비공개"
- 구독: "구독 캘린더" / "Google·Apple 캘린더에서 팀 일정을 자동으로 받아요" / 버튼 "구독 링크 복사" / 토스트 "구독 링크가 복사됐어요"
- 삭제 모달: "일정을 삭제할까요?" / "{날짜} {제목} · 삭제하면 팀원에게 알림이 가요." / [취소/삭제]

## 검증
- 필수: 유형·날짜·시간·장소 (+경기·대회=상대 팀, 대회·훈련=제목) — 미입력 제출 시 인라인 첫 오류 포커스
- 과거 날짜 선택 불가(캘린더 비활성) · 같은 팀 같은 일시 중복 = 인라인 경고(차단 아님 — 더블헤더 존재)

## 정렬·표시
- 목록 = 월 단위, 미래 우선(오늘부터 오름차순 → 종료분 아래 최근순) · 월 전환 화살표
- 허브 "다음 경기" 포맷: "다음 경기 — {M/D}({요일}) {HH:mm} vs {상대}" (teal 700)

## 완료 기준 체크리스트
- [ ] 모달/바텀시트 필드 가변(유형 전환 시 즉시)
- [ ] 카피 원문 일치 · 유형 pill 3색 · 요일 색(일 레드톤)
- [ ] 모바일: 날짜 38px·pill+시간 한 줄·입력 16px
- [ ] 중복 일시 경고(비차단), 월 전환, 종료 자동 파생
