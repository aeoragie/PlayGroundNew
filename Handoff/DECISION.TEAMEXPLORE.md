# DECISION.TEAMEXPLORE — 팀 탐색 검색 주체 + 랜딩 배선 + GNB 퀵서치

> 위치: `Handoff\DECISION.TEAMEXPLORE.md` · DesignWorkOrders ⑦ (② 지원 핸드오프의 선행 결정)
> 형식: 시나리오별 대안 → 추천 + 근거 → 확정 시 배선표 + GNB 퀵서치 SPEC. **[결정 필요] 표시 항목만 답하면 됨.**

## 1. 검색 주체 — 대안과 추천

| 주체 | 무엇을 찾나 | 대안 |
|---|---|---|
| A. 선수·보호자 | 들어갈 팀 (모집중) | 팀 탐색 /teams — 이미 설계·구현됨 |
| B. 팀 관리자 | 영입할 선수 / 친선 상대 | (B1) 선수 탐색 화면 신설 (B2) 선수 검색은 만들지 않음 — 지원·추천으로 수급 |
| C. 에이전트 | 선수·팀 둘 다 | (C1) 본 서비스에 에이전트용 검색 (C2) 에이전트 서비스(별도)의 몫 |

**추천: A = /teams 유지 · B = B2 · C = C2** — 단, 퀵서치의 **이름 검색은 선수 포함**(§3 확정 반영). "조건 검색(디렉터리)"과 "이름 검색(지명 탐색)"을 분리한다 — 전자는 만들지 않고 후자는 제공.

근거:
1. **선수 검색(B1)은 미성년자 디렉터리가 된다** — 성인(타 팀 관리자·에이전트)이 아이를 조건 검색하는 화면은 보호자 신뢰(핵심 가치)와 정면 충돌. 지금까지의 설계(에이전트 열람 승인 30일·연락처 서버 마스킹·공개 범위 스위치)가 전부 "선수는 검색되는 대상이 아니라 공개를 선택하는 주체"라는 원칙 위에 있음.
2. 팀의 선수 수급은 이미 **역방향 파이프라인**이 설계돼 있음 — 모집 공고 → ② 지원(선수가 옴) + 에이전트 추천. 선수 검색 없이 성립.
3. 친선 상대 물색은 팀 탐색으로 충분(팀 대시보드 메뉴 하단 보조 링크 — 7/21 보강 반영됨).
4. 에이전트 고급 검색(성적·연령 조건)은 설계 결정 4(별도 서비스)의 몫 — 본 서비스는 열람 승인 심사만.

**파급 효과**: ② 지원의 진입 동선 = "선수가 팀을 찾아와서 지원"으로 단순화. 팀 측 화면은 지원자 리스트(수신함)만.

## 2. 랜딩 역할 카드 배선 (현재 둘 다 /login 임시)

| 카드 | 목적지 (게스트) | 근거 |
|---|---|---|
| "팀을 찾고 있어요" (선수·보호자) | **/teams** — 로그인 없이 바로 탐색 | 가치 선체험 → 지원 시점에 로그인 요구(returnUrl) |
| "선수를 찾고 있어요" (팀) | **랜딩 팀 소개 절 앵커 → 절 내 CTA로 /auth?intent=team** | 확정(7/24): 가치 설명 후 온보딩 — 설득 후 전환 |

- 카드 카피는 현행 유지, 링크만 교체. 히어로 보조 CTA "우리 동네 팀 둘러보기"(→/teams)는 기존 보강 결정 그대로.

## 3. GNB 퀵서치 SPEC (7/24 확정 반영)

- ~~[결정 필요 ②]~~ **확정(7/24): 선수 이름 검색 유지** — 사용자 근거: 지인·유명 선수를 이름으로 찾아보는 수요가 실재하고 이를 제공하는 서비스가 없음(차별점). 미성년자 보호 관점과의 절충으로 아래 **안전장치 4개**를 전제:
  1. **이름 검색만, 디렉터리 금지** — 선수는 2글자 이상 이름 입력에만 결과 노출. 연령·포지션·성적 조건으로 선수를 목록화하는 화면은 여전히 없음(/teams는 팀 전용 유지)
  2. **공개 스위치 존중** — 프로필 비공개·검색 비노출 설정 선수는 결과 제외(SoccerPlayerFieldVisibilities에 "검색 노출" 항목 추가 — 기본 켜짐, 보호자가 끌 수 있음)
  3. 결과 행 = 이름+소속팀·연령대만(사진·스탯 X) → 클릭 시 공개 프로필(기존 공개 범위 규칙 적용)
  4. 동명이인 다수 시 소속팀으로 구분 — 연락처·학교 등 식별 정보는 결과에 절대 미노출
- 그룹핑: 팀 / 선수 2그룹(SearchFilter 카탈로그 원안 유지) — 각 최대 3건 + "'{q}' 전체 결과 보기"(팀만 /teams?q= — 선수는 전체 결과 페이지 없음, 퀵서치 내 5건까지만)
- 노출: 게스트 포함 전 화면 GNB(공개 팀 홈 제외 — 팀 자체 사이트 원칙). 결과 행 2줄(nowrap). PC 드롭다운 / 모바일 풀스크린·최근 검색어 3개(로컬) — SearchFilter 규칙 그대로.
