# DECISION.OGMETA — 링크 공유 미리보기(OG 메타) 아키텍처 + 카드 규격

> 위치: `Handoff\DECISION.OGMETA.md` · DesignWorkOrders ⑨
> 사용자 확정(7/25): **선수 프로필 OG 카드는 이름만 노출** — 사진·소속·기록 미포함.
> 남은 **[결정 필요]** 표시 항목만 답하면 됨.

## 0. 문제
Blazor WASM은 클라이언트 렌더 — **카카오톡·페이스북·X 크롤러는 JS를 실행하지 않는다.** 지금 상태로 링크를 공유하면 제목·이미지 없이 URL만 노출된다. 태그를 **서버가 응답하는 HTML에 실어야** 한다.

## 1. 아키텍처 — 대안과 추천

| 대안 | 방식 | 평가 |
|---|---|---|
| A. 정적 index.html에 고정 태그 | 모든 링크가 같은 카드(랜딩 카드) | 비용 0이지만 팀·선수·대회 구분 불가 — 공유 유입 목적을 못 살림 |
| **B. 크롤러 감지 → 서버 미니 HTML (추천)** | User-Agent가 크롤러면 ASP.NET 미들웨어가 **메타 태그만 있는 최소 HTML** 반환, 사람은 그대로 SPA | 라우트별 카드 가능 · 구현 작음(미들웨어 1개 + 라우트별 메타 조립) · SEO도 부수적으로 개선 |
| C. 전면 서버 프리렌더(SSR) | Blazor Server/SSR 전환 | 카드 하나 때문에 아키텍처를 바꾸는 격 — 과도 |

**추천: B.** 대상 라우트만 화이트리스트로 처리(`/team/{slug}`, `/player/{id}`, `/records/{id}`, 랜딩) · 그 외는 랜딩 카드 폴백.

**[결정 필요 ①]** B 승인 여부.

## 2. 카드 콘텐츠 규격 (1200×630)

| 라우트 | 제목 | 설명 | 이미지 |
|---|---|---|---|
| 랜딩 `/` | PlayGround Soccer | "유소년 축구 팀·선수·기록을 한곳에서" | 정적 브랜드 카드 1장 |
| 팀 홈 `/team/{slug}` | {팀명} | "{지역} · {연령} · 선수 {N}명" | **동적**: 네이비 배경 + 엠블럼 + 팀명(엠블럼 없으면 이니셜 실드) |
| 선수 프로필 `/player/{id}` | **{선수 이름}** | **"PlayGround Soccer 선수 프로필"** (고정 문구) | **정적 브랜드 카드**(선수별 이미지 생성 안 함) |
| 경기기록 상세 `/records/{id}` | {대회명} | "{연령} · {기간} · {참가 팀 수}" | 동적: 네이비 배경 + 대회명 |

### 선수 프로필 카드 — 확정 규칙 (7/25)
- **이름만** 노출. **사진·소속팀·연령·기록·강점 태그 전부 미포함**
- 설명은 개인화하지 않는 **고정 문구** — 카톡 대화방에 아이 정보가 남지 않게
- 이미지도 **선수별 생성 안 함**(공통 브랜드 카드) — 아이 얼굴이 링크 미리보기로 유통되는 경로를 원천 차단
- **비공개·검색 노출 끔 선수**는 OG 태그 자체를 생성하지 않고 랜딩 카드 폴백(존재 확인 불가)
- 근거: 프로필 본문의 공개 범위 스위치는 "방문한 사람"에게만 적용되는데, OG 카드는 **링크가 전달된 모든 사람**에게 미리보기로 뜬다 — 통제 밖 유통이므로 최소 정보만.

## 3. 이미지 생성 방식
- 팀·대회 카드는 **서버 렌더 PNG**(SkiaSharp 등) + **24시간 캐시**(엠블럼·팀명 변경 시 무효화)
- 실패·미존재 시 정적 브랜드 카드 폴백(빈 이미지 금지)
- 트위터 카드는 `summary_large_image`, 카카오는 OG 태그 그대로 사용

## 4. 태그 목록 (최소 세트)
`og:title` · `og:description` · `og:image`(절대 URL) · `og:url`(정규 URL) · `og:type=website` · `og:site_name=PlayGround Soccer` · `og:locale=ko_KR` · `twitter:card=summary_large_image`

## 5. 확정 후 후속 작업
1. 크롤러 감지 미들웨어 + 라우트별 메타 조립(화이트리스트 4종)
2. 동적 카드 렌더러(팀·대회) + 24시간 캐시 + 정적 폴백 카드 1장 디자인
3. 선수 프로필 = 이름 + 고정 문구 + 브랜드 카드(비공개는 폴백)
4. 공유 검수: 카카오톡 디버거·페이스북 셰어링 디버거로 4종 라우트 확인
